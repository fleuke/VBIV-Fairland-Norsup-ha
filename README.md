# VBIV-Fairland-Norsup-ha
Home Assistant integration for VBIV pool heat pumps (VB Klimaattechniek / Pollet Pool Group) via Modbus TCP using an EW11A WiFi-RS485 adapter. Includes verified register map, HA YAML config, Lovelace dashboard and Python test scripts. Likely compatible with Norsup, Fairland and other PC1004-based pumps.
